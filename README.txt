What do you need to run to see the widget?
1) Download and unpack weather-widget.zip (link above).
2) Open the weather-widget folder.
3) Double-click on install.bat.
He will find/install Python himself, assemble WeatherWidget.exe , it will create a "Weather" shortcut on the desktop and in the Start menu, ask about autorun, and at the end it will prompt you to open the widget immediately. Next, just open it with a shortcut, just like any other program.
